# Xisnove

Xisnove is an API-first, cloud-native monitoring system written in Go. The
current milestone supports HTTP/TLS, TCP, and resolver-pinned DNS monitors
stored in SQLite, local Turso Database, managed Turso Cloud, or PostgreSQL;
work is leased by capability to outbound Agents, projected into health, and
promoted into Incidents after failures or durable staleness.

This is intentionally smaller than the full v1 roadmap. Kubernetes discovery
and CRDs, notifications, UI, CLI, and release packaging remain future
milestones.

The public contract is [api/openapi.yaml](api/openapi.yaml). Root code contains
the control plane and public Go SDK; `agent/` is an independently buildable Go
module that knows the control plane only through its generated API client.

Quick verification:

```bash
make check
go test -race ./integration -run 'TestFirstObservation|TestProtocolBreadth|TestStorageMatrix'
```

Portable local CI uses Dagger CLI `v0.21.8` and same module as GitHub Actions:

```bash
make dagger-ci
# equivalent: dagger call local-ci --source=. --run-nonce="$(date +%s)-$$"
```

The TypeScript SDK under `.dagger/sdk` is runtime-generated by Dagger and
intentionally ignored. Do not replace it with a checked-in SDK copy.
